# Code of Conduct

This project follows the [Contributor Covenant][cov], version 2.1.

The full text lives at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short:

- Be respectful and patient with each other.
- Assume good intent. Ask before assuming the worst.
- Critique ideas, not people.
- Keep discussion focused on the project and the work.

## Reporting

Issues with conduct in this project's spaces (issues, PRs, discussions)
can be reported privately to [@nstefanelli](https://github.com/nstefanelli)
on GitHub. Reports are confidential. Action will be taken in good faith
and proportionate to the situation.

## Scope

This code of conduct applies to all project spaces — the GitHub repo,
issues, pull requests, discussions, and any related communication
channels — and to anyone representing the project in public.

[cov]: https://www.contributor-covenant.org/
